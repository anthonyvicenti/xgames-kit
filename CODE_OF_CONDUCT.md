# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be welcoming, be kind, give and take feedback gracefully, and leave out harassment of any kind. It applies in
this repository's issues, pull requests and discussions, and anywhere you represent the project.

To report a problem with someone's conduct, use the same private channel as a security report
([SECURITY.md](SECURITY.md)) and say it is about conduct. Reports are read by the maintainers only and kept private;
the Covenant's enforcement guidelines say what may follow.
